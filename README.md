# Domain Available for Transfer (At Cost Price)

This repository hosts a simple, lightweight landing page for a domain name offered for ownership transfer strictly at its original acquisition cost.

## 📌 Purpose

The domain was purchased on impulse and is currently not needed for any project. The goal is to pass it on at **cost price with zero markup or profit** to someone, a startup, or a project that can actually make use of it.

## 🛠️ Features

- **Language Support:** Bilingual interface in Finnish (Suomi) and English (EN).
- **SEO & AI Ready:** Includes Schema.org (`Product` / `Offer`) JSON-LD structured data and Open Graph meta tags to help search engines and AI models identify the transfer offer.
- **Privacy & Security:** Lightweight, fully static HTML page with no tracking scripts or dependencies.
- **Zero Profit:** Purely created to facilitate a direct, transparent domain transfer.

## ⚙️ Deployment

Hosted using **GitHub Pages** with a custom domain setup.
